# 00_START_HERE

## 프로젝트 한 줄 요약

**안심트랙 Live**는 현재 모니터에 보이는 재난안전 영상을 읽어서, 경계선지능인도 따라갈 수 있게 장면을 판단 지점 단위로 나누고 멀티트랙으로 다시 설명하는 데스크톱 플레이어다.

## 가장 중요한 원칙 8개

1. 대회용 목표는 **범용성**이 아니라 **시연 완성도**다.
2. macOS 단일 경로를 먼저 완성한다.
3. 원본 영상 위에 바로 개입하는 HUD보다 **Shadow Player**가 본체다.
4. 세그먼트는 샷이 아니라 **판단 전환 지점** 기준으로 자른다.
5. 한 세그먼트에는 **한 행동만** 남긴다.
6. 행동 문장은 반드시 **공식 재난행동요령**에 근거해야 한다.
7. 여러 트랙을 한 번에 보여주지 않고 **선택형 트랙**으로 간다.
8. 예쁜 화면보다 중요한 것은 **멈춤, 반복, 쉬운말, 근거 표시, Panic Mode**다.

## 최종 데모의 성공 조건

- 심사위원이 10초 안에 “무슨 문제를 푸는 제품인지” 이해한다.
- 1분 안에 “기존 자막/요약과 뭐가 다른지” 이해한다.
- 3분 안에 “왜 경계선지능인에게 실제로 도움이 되는지” 이해한다.
- 잘못된 행동 지시를 하지 않는다.
- 화면이 깔끔하고 반응이 빠르다.

## 필수 기능(P0)

- macOS ScreenCaptureKit 캡처
- 4초 지연 Shadow Player
- 화재/지진 rule grounding
- basic/easy/action/reason/caregiver/report 트랙
- 세그먼트 카드
- Panic Mode
- 근거 패널
- 음성 재설명 4개 intent

## 있으면 좋은 기능(P1)

- 브라우저 탭 fallback
- 객체 하이라이트(SAM2)
- 자동 pause
- 다시 보기 루프
- 로그/텔레메트리

## 과감히 버릴 수 있는 기능(P2)

- 범용 모든 재난 지원
- 개인화 추천
- 다국어
- 클라우드 협업
- 복잡한 사용자 계정 체계
