# 01_PROJECT_SCOPE_AND_SUCCESS_METRICS

## 문제 정의

재난안전 영상은 빠르게 지나가고, 정보 밀도가 높고, 행동과 이유가 압축되어 있다. 경계선지능인에게는 이런 형식이 작업기억과 추론 부담을 크게 만든다. 따라서 제품은 **영상 이해 자체**보다 **행동 결정의 단위화**를 목표로 해야 한다.

## 사용자

### 1차 사용자
- 경계선지능인
- 느린학습자
- 인지 처리 속도가 느린 사용자

### 2차 사용자
- 보호자
- 교사/사회복지사/생활지도사
- 재난안전 교육 담당자
- 경진대회 심사위원(시연 관점의 소비자)

## 사용 시나리오

1. 사용자가 유튜브 또는 공공포털에서 화재 행동요령 영상을 재생한다.
2. 안심트랙 Live가 현재 모니터를 읽기 시작한다.
3. 앱은 4초 지연된 Shadow Player에 같은 영상을 재생한다.
4. 재난 유형과 현재 세그먼트를 감지한다.
5. 사용자는 원하는 트랙을 선택하거나 음성으로 설명 방식을 바꾼다.
6. Panic Mode에서 핵심 행동만 본다.

## 범위 내

- 재난안전 영상
- 화재/지진 우선
- 공식 행동요령 기반 설명
- 로컬 데스크톱 사용
- 부분적 실시간성(3~5초 지연 허용)

## 범위 밖

- 완전 범용 영상 분석
- 자유 생성형 행동지시
- 장기 사용자 프로필 기반 개인화
- 멀티유저 협업
- 의료/법률/실시간 긴급 통화 자동화

## 성공 지표

### 제품 지표
- 세그먼트 카드 생성 지연: 2초 이하
- 음성 재설명 응답 시작: 1초 이하
- Shadow Player 안정 재생: 10분 이상
- 앱 크래시 없이 5회 연속 데모 성공

### 설명 품질 지표
- 행동 트랙이 공식 rule id를 100% 가진다
- 저신뢰 상황에서 fallback이 정상 동작한다
- 수작업 검수에서 행동 hallucination 0건
- 데모 영상 20개 샘플 중 세그먼트 경계 수용률 80% 이상

### 대회 지표
- 3분 시연 안에 핵심 차별점 전달
- 시연 중 수동 조작 5번 이하
- 심사 질문에 대해 근거 화면 즉시 제시 가능

## MVP 완료 정의

아래 항목이 모두 되면 MVP 완료로 본다.

- macOS에서 모니터/창 캡처
- Shadow Player에 4초 지연 재생
- 화재/지진 2개 도메인 인식
- 세그먼트 카드 기본 표시
- 6개 트랙 중 최소 4개 동작
- 음성 재설명 4개 intent 동작
- Panic Mode
- 근거 패널
